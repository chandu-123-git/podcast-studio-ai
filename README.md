# 🎙️ AI Podcast Generator

An AI-powered podcast generation system that transforms a user-provided topic into an audio podcast using n8n, AI, and Murf text-to-speech.

## Features

- Topic-based podcast generation
- AI-powered content creation
- Murf AI text-to-speech conversion
- Webhook-based frontend and backend integration
- Audio playback through a web interface

## Tech Stack

- n8n
- Murf AI
- AI Language Model
- Lovable
- REST APIs
- Webhooks

## Workflow

```text
User Topic → n8n Webhook → AI Content Generation
→ Murf Text-to-Speech → Audio URL → Audio Player
```

## Files

- `n8n-podcast-workflow.json` — n8n automation workflow

## Security

API keys and sensitive credentials have been removed. Configure your own credentials in n8n before running the workflow.
